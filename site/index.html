Give your agent the web. With sources.

Trovia searches, reads the top pages, and hands back only the passages that answer the question, cited. It runs on your own machine. No account, and no API key to start.

$ curl -LsSf https://abyssalwolf.github.io/trovia/install.sh | sh

Then run trovia. A short setup asks for optional API keys and your defaults. Needs no Python of your own.

Read install.sh before you run it. Open source, Apache 2.0. Remove it any time with uv tool uninstall trovia.

A normal search engine hands your agent links and leaves the reading to it. Trovia does the reading. Here is what that looked like on real advanced searches.

  1. 1Search

    Brave, then Serper, then your SearXNG, then DuckDuckGo. If one fails or runs out of quota, the next takes over.

  2. 2Read

    Each page becomes clean Markdown. If a page can't be read, its search snippet stands in.

  3. 3Split

    Passages of about 800 characters. Code blocks stay whole, and the search snippet counts as a passage too.

  4. 4Rerank

    A 3 MB model on your CPU keeps the best. About 100 MB of memory idle, around 400 MB in use.

Set it up once. Change it any time.

The first run asks for optional API keys and three defaults, each with a recommended value. Keys are hidden as you type and checked with one real search. Later, trovia config changes anything, and a running service picks it up on the next search.

The defaults we recommend

Passages returned per search

Advanced searches read at least eight pages and return twice as many passages. Every search can override all three.

Start free. Add a key when it matters.

Trovia tries your providers in order and skips any you have not set up.

Provider Needs Good to know
DuckDuckGo Nothing. Built in. Free and best-effort. It can rate-limit you for a minute or two.
Brave Search API key A monthly credit covers roughly 1,000 searches; a card is required. Trovia stops at your monthly cap.
Serper API key Google results. New accounts get a free starter allowance.
SearXNG Docker Optional and self-hosted, for advanced setups. Queries several engines at once.

One line for MCP. One request for REST.

MCP

Claude Code, Claude Desktop or any MCP client gets a web_search tool. The service does not even need to be running.

claude mcp add trovia -- trovia mcp
web_search(
  query,
  search_depth="basic",      # or "advanced"
  max_chunks=None,           # your default: 6
  max_chunks_per_page=None,  # your default: 2
)

REST API

Run trovia and call it from anything that speaks HTTP. Interactive docs live at /docs.

curl -X POST http://localhost:8000/v1/search \
  -H "Content-Type: application/json" \
  -d '{"query": "tokio mutex vs std mutex"}'
{
  "search_provider_used": "brave",
  "synthesized_context": "## Source: ...",
  "results": [ ... ],
  "error": null
}

Teach your agent to use it.

Two ready-made agent skills. Unzip one into your agent's skills folder (for Claude Code, ~/.claude/skills/) and the agent knows when to search, which options to pick, and to cite what it finds.

  • trovia-mcp

    Installs Trovia with your permission, registers the MCP server, and uses the web_search tool well.

    Download

  • trovia-rest-api

    Calls the REST API directly from scripts or any HTTP client, and handles errors the way Trovia reports them.

    Download

What it does not do.

  • No JavaScript renderingPages that only appear after scripts run fall back to Jina, then to their snippet.
  • Not instantA fresh search takes about 4 to 11 seconds, mostly reading pages. Repeats come from the cache in milliseconds.
  • Local onlyNo authentication. It listens on 127.0.0.1 and refuses requests from other host names.
  • Python 3.11 to 3.14The installer finds or downloads a compatible one for you.
